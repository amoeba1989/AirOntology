# 本体学习工作台（V2.1）

本次实现第二阶段计划的前三项：本体词典、SPARQL 查询练习台、SHACL 数据校验。入口为页面导航“本体学习工作台”，位于原有 TBox/ABox 面板下方。

## 1. 本体词典：从中文术语读懂 OWL

搜索“阵地”“观测记录”或英文标识，点击术语可查看中文说明、URI（资源标识）、类型、domain（定义域）、range（值域）、关系及对应 Turtle 文本。类展示显式属于该类的实例；属性展示“主语—谓语—宾语”的实际取值。实例范围是最多 100 架无人机的当前事实、当前阵地与规则，最多展示 20 个匹配，不包含全部历史。再次点击术语会刷新实例。

`a` 表示“属于某类”；`rdfs:label` 是名称；`@zh` 是中文语言标记。OWL 描述概念与关系，是否必填、必须几个值由 SHACL 约束，不能将 OWL 值域当作输入校验。

展开 Protégé 练习区，下载当前模型；使用 Protégé（本体编辑工具）打开并另存为 Turtle。可新增一个“飞行任务”类并设置中文标签，然后选择导出的 `.ttl` 文件，点击“校验模型语法与术语”，通过后“导入独立学习模型”。也可直接编辑文本。

导入模型存放在 `http://counteruav.org/counterUav#graph/learning-schema` 命名图，重启后仍保留；只替换学习词典，**不改变业务 TBox、实例数据和距离计算**。清除学习模型后恢复业务词典。业务 TBox 变更仍应通过代码评审与发布完成。导入基本检查包含 Turtle 语法、至少一个 OWL 类或属性及术语标签；不执行 OWL 一致性推理、不加载外部 imports。上限为 32KB 文本、3000 条三元组、200 个术语。

## 2. SPARQL 查询：从中文问题走到业务事实

提供五个只读模板：

| 中文问题 | 学习要点 | 数据范围 |
|---|---|---|
| 当前有哪些无人机 | SELECT 选择列、GRAPH 指定命名图 | state 当前目标，包含过期数据，显示观测时间 |
| 选中阵地阈值内有哪些无人机 | 跨图关联、FILTER 筛选、排序 | 最新评估、当前规则版本、有效时间内、低关注阈值内 |
| 选中无人机的评估依据是什么 | 对象属性关联 | 最新评估关联的观测、阵地、规则；可能过期 |
| 最近上报过哪些位置 | 历史时间排序、LIMIT 限制数量 | history 中最近 100 条仍保留的观测 |
| 数据分别存在哪些图中 | 命名图、COUNT 计数、GROUP BY 分组 | 四个业务图的三元组计数 |

运行后展示实际执行的语句、变量、结果、执行时间；结果中的无人机、阵地在地图加蓝色外框，点击行可选中页面中的对应对象，支持清除高亮。历史位置只展示在表格，不替换地图对象的当前或回放坐标。查询始终读取实时业务图，不随历史回放切换，也不查询导入的独立学习模型。

每次只在点击时执行，最多返回 100 行；服务器只接受模板编号和经过验证的业务 ID，不接受任意 SPARQL、更新语句或 SERVICE 外部查询。原有 RDF 查询仍由 Fuseki 执行。

## 3. SHACL：解释图数据为什么不合格

使用 pySHACL 执行 `ontology/shapes.ttl`，保持 `inference='none'`，不启用 SHACL-JS、高级规则或外部导入。校验观测时间、经纬度类型与范围、观测关联目标、评估的目标/阵地/观测/规则数量、评估距离以及阵地名称和坐标。

依次操作“载入正常样例 → 校验编辑器样例”“载入异常样例 → 校验编辑器样例”。异常样例故意去掉观测时间、将经度改为文本、让同一评估关联两个阵地。报告提供中文问题、对象 URI、属性 URI 和命名的约束位置，可查看并下载报告 RDF / TTL。样例可编辑，限 32KB / 3000 条三元组，不写入业务数据库。

“校验当前实时 RDF”检查最多 100 架无人机的最新观测与评估、规则及当前阵地，不扫描全部历史。SHACL 当前只针对显式声明为 Observation、Assessment、Position 的实例；没有受检对象时会显示受检数 0，不能据此认为业务数据完整。Pydantic 继续校验 MQTT/API 输入；SHACL 作为按需学习与诊断功能，不自动阻塞实时接入。每个后端进程同时只运行一个校验任务。

## 演示脚本

1. 在地图选择无人机与阵地，查看一条距离告警及其观测、规则依据。
2. 打开词典查看“评估记录”类，再查看 basedOnObservation（依据观测）对象属性，读懂三元组。
3. 运行“评估依据是什么”查询，对照 SPARQL、结果表与地图高亮。
4. 查询历史位置和四个命名图，区分 TBox、当前状态、历史与配置。
5. 校验正常与异常样例，逐项解释 SHACL 中文报告。
6. 可选：用 Protégé 修改导出的模型，校验并导入独立学习模型，然后恢复业务词典。
