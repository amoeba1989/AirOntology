# 本体证据问答：本地预览

本版提供三个预设问题：距离阵地最近的目标、距离关注优先顺序，以及高关注距离圈内的目标。选中阵地后提问，结果固定在提问时刻；过期、未来时间、缺少评估或规则已变更的对象会被排除并说明原因。

后端读取业务 RDF 图中的最新观测、针对所选阵地的评估和规则快照，从本体策略读取筛选与排序字段，由程序执行计算。高关注距离圈查询使用 `high-zone-policy-v1` 声明的 `requiredDistanceLevel`。距离关注等级只表示距离阈值，不代表综合威胁、违法或设备探测能力。

针对返回的候选，后端抽取一组有界、带编号的真实 RDF 三元组，包含本体策略、相关观测、阵地、评估、规则快照及本次计算结果，并与结构化结果一起发送给 DeepSeek。界面中的证据列表与模型请求中的三元组一致；点击回答中的 `[E编号]` 可以定位对应三元组。界面检查编号是否存在，但不自动证明模型的文字推论正确；距离、名次和排除原因以程序结果为准。

查询最多读取按目标编号排序的前 100 个目标，最多返回 10 个候选。模型只收到返回候选相关的三元组和汇总数字，不代表读取了全部历史或完整知识图谱。本版不支持自由问题、模型执行任意 SPARQL 或通用 OWL 自动推理。

## 独立本地预览

完整服务仍可使用现有 `./start-local.sh`。如果本机暂时无法下载 Docker 镜像，可以运行内存 RDF 预览：它使用与正式版相同的后端问答和规则代码，模拟 4 架无人机、2 个阵地及设备；它不连接 ECS、Fuseki 或 MQTT，预览数据在进程结束后清空。

需要 Python 3.12 或更新版本与 Node.js。首次在项目目录执行：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements-dev.txt
cd frontend && npm ci && npm run build && cd ..
.venv/bin/python scripts/preview_memory.py
```

打开 `http://127.0.0.1:8093`，选择阵地，点击右下角“态势问答”。默认每 10 秒产生一帧模拟观测、每架保留最近 10 条，并让一架模拟无人机在一号阵地高关注距离圈内，便于体验三个问题。

如需真实模型解读，在本机已有且被 Git 忽略的 `.env` 中配置 `DEEPSEEK_API_KEY`；也可以由启动进程的环境变量提供。不要把密钥写进代码或提交仓库。没有密钥时界面明确展示规则结果，不声称调用了模型。使用真实模型时，相关模拟观测三元组会发送给所配置的 DeepSeek 服务。
