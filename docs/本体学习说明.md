# 本体学习说明

## 先看业务，再看语法

本项目描述：无人机001关联一号阵地，程序计算二者水平距离，并记录距离关注等级。

- **模型定义**：有“无人机目标”“阵地”“距离关注等级”三个类别，有位置、距离等属性及关联阵地等关系。
- **实例事实**：无人机001是无人机目标，它的位置是多少、关联哪个阵地、当前距离和等级是多少。

RDF是三元组数据模型；OWL用于定义本体语义；TTL是文本格式；Fuseki提供存储和查询服务；SPARQL用于查询和更新。Python负责本项目的距离计算与等级判断。

## 对照一段代码

```turtle
@prefix cu: <http://counteruav.org/counterUav#> .
@prefix owl: <http://www.w3.org/2002/07/owl#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

# 类别定义
cu:Position a owl:Class ;
    rdfs:label "阵地"@zh .

# 数值属性定义
cu:distanceToPosition a owl:DatatypeProperty ;
    rdfs:label "到阵地水平距离（米）"@zh ;
    rdfs:range xsd:double .

# 以下仅演示实例语法，不表示完整的实时记录
cu:pos001 a cu:Position ;
    rdfs:label "一号阵地"@zh .
```

| 写法 | 中文含义 |
| --- | --- |
| @prefix | 声明名称前缀的简写 |
| cu: | 我们自己定义的业务名称前缀，可换名但需保持声明一致 |
| a | rdf:type的简写，表示“是……的实例” |
| owl:Class | 类 |
| owl:ObjectProperty | 对象属性，连接对象与另一个对象 |
| owl:DatatypeProperty | 数据属性，连接对象与数值、文字等 |
| owl:NamedIndividual | 有名字标识的实例 |
| rdfs:label | 供人阅读的名称 |
| rdfs:comment | 说明文字，不是可执行计算规则 |
| rdfs:domain | 属性定义域，具有语义含义，不替代输入校验 |
| rdfs:range | 属性值域，具有语义含义，不替代输入校验 |
| xsd:double | 双精度浮点数 |
| xsd:dateTime | 日期时间类型 |
| @zh | 前面的文字为中文 |
| 分号 ; | 主语不变，继续描述同一对象 |
| 句号 . | 语句结束 |

## 在页面中学习

1. 看“中文结构”，先认识类和两类属性。
2. 切换“本体定义TTL”，找到相同英文标识和中文label。
3. 观察地图，等待距离和等级变化。
4. 切换“当前实例TTL”，找到位置、距离、阵地和等级。
5. 对照理解：静态定义没有随位置变化，变化的是实例事实。

本项目不需要学习推理。OWL文件中只使用基础定义；没有配置推理器，也不宣称OWL会自动判断距离等级。

## 手动查询示例

以下查询在Fuseki的`/counteruav/query`接口执行，注意本项目使用命名图。

```sparql
PREFIX cu: <http://counteruav.org/counterUav#>
SELECT ?target ?distance ?level
WHERE {
  GRAPH <urn:airontology:state> {
    ?target a cu:BlueDevice ;
            cu:distanceToPosition ?distance ;
            cu:hasDistanceLevel ?level .
  }
}
```

中文意思：在最新状态图中，查出无人机目标及其距离、等级。
